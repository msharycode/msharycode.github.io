# مشاري — موشن جرافيك ومواقع رقمية

موقع عربي متخصص بقطاع الشاحنات وقطع الغيار. يعرض أعمال تليد وجديد وحبان المتحدة في شريط أفقي متحرك، وشعارات العملاء، ومعاينة الواجهة الرئيسية لتليد وجديد، مع نبذة وخدمتين تفاعليتين وطلب مشروع عبر واتساب.

شغّل `python -m http.server 3000` من مجلد المشروع. لا يحتاج بناءً أو تثبيت حزم. النشر عبر GitHub Pages من main. الفيديوهات تُحمّل عند اختيار المشاهدة فقط. يتوقف التحريك أثناء التفاعل وعند تفعيل تقليل الحركة، وتتوفر أزرار تنقل وإيقاف.

الخطوط والأعمال والشعارات تخص أصحابها، وترخيص ثمانية مرفق في assets.
