# مشاري ناجي — معرض الأعمال
موقع عربي ثابت لعرض أعمال الموشن جرافيك والمواقع، مع فصل أعمال تليد وجديد وحبان المتحدة وشعبيات الطيبين، وتعريف مهني وخدمات تفاعلية وتواصل عبر واتساب.

## التشغيل
`python3 -m http.server 3000` ثم افتح http://localhost:3000. لا يحتاج الموقع إلى تثبيت حزم أو بناء. يعمل مباشرة عبر GitHub Pages من الفرع main وجذر المستودع.

## الملفات
- `index.html`: المحتوى والهيكل.
- `portfolio.css`: التصميم المتجاوب والحركة واحترام تقليل الحركة.
- `portfolio.js`: تشغيل الفيديو عند الطلب، تبويبات الخدمات والمراحل، وتجهيز رسالة واتساب.
- `assets/work/`: معاينات WebP ونسخ فيديو MP4 محسنة للويب.
- `fonts.css` و`assets/fonts/`: خطوط ثمانية الأصلية مع الترخيص الموجود في assets.

لا تُحمّل ملفات الفيديو قبل اختيار تشغيلها. لا يوجد تشغيل تلقائي عند فتح الصفحة، ولا نماذج ترسل بيانات إلى خادم. طلب المشروع يجهز رسالة يراجعها الزائر ويرسلها بنفسه في واتساب.

محتوى المكتبات والبرومبتات التعليمية أزيل من واجهة الموقع؛ رابط مسار الموشن القديم يعيد التوجيه إلى الأعمال.

الصور والفيديوهات والشعارات المعروضة أعمال وأصول تخص أصحابها. خط ثمانية مستخدم ضمن المشروع وفق الترخيص المرفق، ولا يُعاد توزيعه منفصلًا.
