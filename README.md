# مشاري

الموقع الشخصي لمشاري: أعمال وأدوات ومكتبة موارد لتطوير المواقع.

- هوية عربية بخط ثمانية، وأزرق `#2954C8` وأبيض دافئ `#F8F7F3`.
- أعمال: شعبيات الطيبين وجهّز صورتك.
- خمس مكتبات ومراجع: Apple Design Skill، Lucide، Motion، Swiper، Zod. لكل مورد شرح وطريقة استخدام وبرومبت نسخ داخل قسم GitHub.
- بحث وتصنيفات ومحفوظة محلية ودليل لبناء موقع شخصي ثابت ونشره.
- طلب المشروع يجهّز رسالة بريد للمراجعة؛ لا يرسلها الموقع ولا يخزنها.

## الملفات

عدّل `content.js` لإضافة الموارد. تعمل الصفحة من خادم ملفات ثابتة دون تثبيت أو بناء. إعداد GitHub Pages: `main` و`/(root)`.

## الحقوق

خط ثمانية مستخدم ضمن حزمة الموقع وفق الترخيص الموجود في `assets/thmanyah-font-license.pdf`. لا يُعاد توزيع الخط مستقلاً. الشعارات وصور الأعمال ومصادر المكتبات تخضع لحقوق أصحابها؛ لا يمنح هذا المستودع ترخيصًا عامًا بإعادة استخدامها.
